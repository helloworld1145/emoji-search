## 用户需求

用户认为首次进入 App 的引导选择文件夹页面「AI 味过重」，决定直接去掉该引导页，让软件更轻量化、首次打开直接进入首页，不再展示引导流程。

## 产品概述

移除「表情包管家」首屏的引导页（Onboarding）。用户首次（及后续）启动 App 时，根路径直接跳转到首页 `/home`，由首页空状态引导用户点「选择文件夹」添加表情包目录。删除后整条引导链路（引导页、完成标记、首屏守卫判断）不复存在。

## 核心改动

- 删除首次启动的引导页视图与文案。
- 根路径 `/` 由「重定向至引导页」改为「重定向至首页 `/home`」。
- 移除引导完成标记 `markOnboardingDone`、首屏 `isOnboardingDone` 判断与 `beforeEach` 守卫。
- 用户仍可进入首页后，通过首页空状态或文件夹管理面板「选择文件夹」手动授权目录。

## 技术栈

- 前端：Vue 3 + TypeScript + Vite + Vue Router（与现有项目一致，不引入新依赖）
- 删除型改动，复用现有路由与 Pinia 初始化机制

## 实现方案

### 总体策略

直接删除引导页视图文件，并清理路由器中与之相关的路由、重定向、完成标记与导航守卫；将根路径静态重定向到首页。难点不在删除本身，而在于确认移除后「初始化逻辑不丢失」。已确认 `src/views/Home.vue` 的 `onMounted` 已自行调用 `emojiStore.init()`、`collectionStore.loadCollections()`、`trashStore.refreshCount()`，因此引导页删除后首页初始化完全自包含，无需迁移。

### 关键技术决策

1. **根路径改为静态 `redirect: '/home'`**：原 `beforeEach` 守卫负责「已引导用户跳过引导页」的判断，删除引导页后该判断失去意义，直接静态重定向最简洁、零运行时开销，也避免异步守卫带来的首屏闪烁。
2. **彻底移除 `markOnboardingDone` / `ONBOARDING_DONE_KEY` / `isOnboardingDone`**：经搜索这些符号仅被 `Onboarding.vue` 与 `router/index.ts` 自身引用，删除无悬空依赖；同时移除其中对 `scanner.listSavedFolders` 的动态 import，避免无意义的首屏扫描调用。
3. **删除 `src/views/Onboarding.vue` 整个文件**：包含其 `onPickFolder`/`onSkip` 等逻辑一并移除；首页的「选择文件夹」入口（`emojiStore.addFolderAndScan`）与空状态引导已存在，功能不丢失。

### 实现注意事项

- 删除引导页后，确保 `router/index.ts` 中不存在对 `onboarding` 路由名或懒加载 `import('../views/Onboarding.vue')` 的任何残留引用，否则会导致打包/运行期模块解析失败。
- 不要改动 `Home.vue`（init 已自包含）与 `App.vue`（TabBar 始终显示，引导页 `hideNav` 语义随之消失，符合预期）。
- `dist/` 中的旧 `Onboarding-*.js` chunk 为历史构建产物，下次 `npm run build` 会自然失效并被清理，无需手动删除。

## 架构设计

改动局限于「视图层 + 路由层」，不涉及数据层（SQLite/Pinia）与原生桥接层。路由表由「根→引导→首页」简化为「根→首页」，其余 6 条业务路由保持不变。

## 目录结构

```
src/
├── views/
│   └── Onboarding.vue        # [DELETE] 删除整个引导页文件（组件、脚本、模板一并移除）
└── router/
    └── index.ts              # [MODIFY] 删除 /onboarding 路由；根路径 redirect 改为 '/home'；移除 markOnboardingDone、ONBOARDING_DONE_KEY、isOnboardingDone、beforeEach 守卫及 listSavedFolders 动态 import
```

## 验证方式

- `npm run dev`：访问根路径直接渲染首页，不再出现引导页（无文件夹时显示空状态并可点「选择文件夹」）。
- `npm run build`：vue-tsc 类型检查与构建通过，确认无残留的 `onboarding` / `markOnboardingDone` 引用。
- 真机/Web 首屏直接进入表情网格；通过首页空状态仍可正常授权并扫描文件夹。
