## 用户需求

在首页（Home）表情网格的多选操作栏中，除现有的「全选 / 删除 / 取消」外，新增一个「批量加入收藏夹」按钮。

## 产品概述

用户进入多选模式并勾选若干表情后，点击「批量加入收藏夹」会弹出收藏夹选择弹层，选择（或现场新建）某个收藏夹后，被选中的全部表情一次性加入该收藏夹，并给出成功提示，操作结束后可继续多选。

## 核心功能

- 多选操作栏新增「加入收藏夹」按钮（带图标，禁用态与删除一致：未选时不可点）
- 点击后弹出底部弹层，复用既有收藏夹选择器，支持选择已有收藏夹或现场新建
- 确认后，将当前 `selectedIds` 中的所有表情批量加入所选收藏夹（含默认总收藏同步、计数刷新）
- 批量完成给出 Toast 提示，保留多选状态以便继续操作

## 技术栈

- 前端：Vue 3 + TypeScript + Pinia + Tailwind CSS（沿用项目既有栈）
- 复用组件：`BaseSheet.vue`（通用底部弹层）、`CollectionPicker.vue`（收藏夹选择，已暴露 `ensureLoaded` 与 `picked` 事件）

## 实现方案

沿用 `EmojiDetail.vue` 已有的「加入收藏夹」弹层模式（`BaseSheet + CollectionPicker`），仅把单张加入改为批量。核心思路：

1. 新增响应式状态 `addToCollectionOpen` 控制弹层显隐。
2. 操作栏模板在「删除」按钮之前插入「加入收藏夹」按钮，绑定 `@click` 打开弹层；未选中（`selectedIds.length === 0`）时 `disabled`，视觉与删除按钮对齐。
3. 新增 `async function onPickedCollection(collectionId)`：遍历 `selectedIds`，逐个调用 `collectionStore.addEmoji(collectionId, id)`；完成后调用 `collectionStore.loadCollections()` 刷新首页收藏夹角标与计数；用既有 `toast` 提示成功（如「已加入 N 张」）；关闭弹层，保留多选状态。
4. 模板复用已导入的 `BaseSheet`（`Home.vue` 第 11 行已引入）与 `CollectionPicker`（第 12 行已引入）、`FolderPlus` 图标（第 4 行已引入），无需新增 import，避免冗余改动与回归。

### 关键决策与合理性

- **复用 `addEmoji` 单张接口循环而非新增批量仓库方法**：`collectionRepo.addToCollection` 本身为 `INSERT OR IGNORE`，重复加入无害；`addEmoji` 已封装 isDefault 总收藏同步与计数刷新，循环调用可零新增持久层代码，符合 DRY/YAGNI。
- **保留多选状态**：批量加入后不清空选择，更贴合连续批量操作体验；如需退出用户可点「取消」。
- **性能**：多选数量通常有限，循环单张写入的 IO 成本可接受，无需事务批处理，避免过度设计。

## 实现注意

- `Home.vue` 第 292 行模板现有 `@click="selectAll"` 实为对 `toggleSelectAll`（第 186 行）的引用，本次不改此处，仅在操作栏增加按钮，避免误碰既有逻辑。
- 弹层内 `CollectionPicker` 的 `:emoji-id` prop 仅用于展示/无实际批量限制逻辑，传空串 `''` 即可（与批量语义无关，组件内部未依赖它做写入）。
- 首次进入首页已完成 `loadCollections`，弹层打开时收藏夹列表已就绪，无需额外调 `ensureLoaded`；为稳妥仍可在打开时调用一次（幂等）。
- 全程使用中文注释，遵循 `CODEBUDDY.md` 约定。
